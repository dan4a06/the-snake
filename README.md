# the-snake
Практическое задание от Яндекс Практикума

Классическая игра «Змейка» на Python с использованием библиотеки Pygame. Проект написан на принципах ООП.

## О чём эта работа

Это первая самостоятельная работа, максимально приближенная к реальной разработке: без тренажёра, с готовым прекодом (графический интерфейс и заготовка игрового цикла) и ТЗ, по которому нужно дописать логику игры.

## Что отрабатывается

**ООП**
- проектирование иерархии классов: базовый `GameObject` и дочерние `Apple` и `Snake`;
- наследование и вызов методов родителя через `super()`;
- переопределение методов (`draw` в каждом дочернем классе);
- инкапсуляция состояния объекта в атрибутах (`position`, `positions`, `direction`, `next_direction`, `last`, `length`);
- разделение ответственности: каждый класс отвечает только за своё поведение.

**Работа со структурами данных**
- список кортежей как модель тела змейки;
- вставка в начало списка (`insert`) и удаление с конца (`pop`) для имитации движения;
- проверка вхождения координат в список (самоукус, появление яблока).

**Игровая логика и алгоритмы**
- перевод координат сетки в пиксели через `GRID_SIZE`;
- «зацикленное» поле: переход через границу с помощью операции взятия остатка (`%`);
- запрет разворота на 180° при смене направления;
- генерация случайной позиции яблока с исключением клеток, занятых змейкой;
- сброс состояния при столкновении змейки с собой.

**Pygame и игровой цикл**
- инициализация окна и настройка частоты кадров через `clock.tick()`;
- обработка событий клавиатуры и закрытия окна;
- отрисовка объектов и «затирание» следа хвоста;
- структура главного цикла: ввод → обновление состояния → проверки → отрисовка.

**Инженерные практики**
- установка и подключение сторонней библиотеки (`pygame`) и штатного модуля (`random`);
- оформление кода по PEP 8 и проверка стиля через `flake8`;
- докстринги и аннотации типов;
- саморевью по чек-листу и работа по ТЗ.

## Правила игры

- Поле 640×480, клетки 20×20.
- Управление стрелками, разворот на 180° невозможен.
- Съеденное яблоко увеличивает змейку на один сегмент.
- Границ нет: змейка выходит с одной стороны поля и появляется с противоположной.
- При столкновении с собой змейка возвращается в исходное состояние.

## Технологии

- Python 3.12
- Pygame 2.5.2
- flake8
